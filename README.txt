RED ROOM V3.0 — Multi-Bank demo

الواجهة الأصلية:
- index.html: لوحة RED ROOM المحلية الأصلية.
- css/styles.css و js/app.js: التصميم والوظائف المحلية القديمة.

النسخة الجديدة ذات السيرفر:
- admin-api.html: لوحة API لإدارة العملاء والمستفيدين والأرصدة.
- customer.html: بوابة دخول العميل والبحث عن المستفيد والتحويل التجريبي.
- server/: Node.js + PostgreSQL backend.

ابدأ من server/README.md لإعداد قاعدة البيانات وتشغيل السيرفر. بعد التشغيل افتح:
- /admin-api.html لإدارة العملاء والمستفيدين.
- /customer.html لتجربة العميل.
- /api/health لفحص السيرفر.

مهم: index.html الأصلي ما زال واجهة محلية مستقلة ولم يتم استبدال LocalStorage فيه بعد. لوحات admin-api و customer هي الواجهات المتصلة بالـ API في هذه المرحلة. النظام محاكاة تعليمية فقط ولا يتصل ببنوك حقيقية ولا ينقل أموالاً حقيقية. لا تستخدم بيانات أو كلمات مرور حقيقية.
